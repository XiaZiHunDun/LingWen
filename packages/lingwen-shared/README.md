# lingwen-shared

Single source of truth for cross-context communication.

## Structure

- `contracts/python/` — Pydantic v2 DTOs (source of truth, manually written)
- `contracts/ts/` — TypeScript types (auto-generated by `tooling/contracts/generate.py`, do not edit)
- `ports/` — Hexagonal port interfaces (Protocol), declared in v16.1, enforced in v16.4/v16.5

## Usage

```python
from lingwen_shared.contracts.python.world import CharacterDTO
from lingwen_shared.ports.llm_service import LLMServicePort
```
