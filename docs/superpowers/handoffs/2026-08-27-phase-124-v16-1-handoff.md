## 5. Lessons

- **hyphen name + underscore module 严格分离** (v16.0 T4.1 deviation 沿用)
- **`ChapterDTO.id optional` TDD-driven 修正** vs 计划 spec 冲突 — TDD discipline 优先
- **Hand-rolled JSON Schema → TS converter** 比 `pydantic-to-typescript` 库更稳 (version drift avoidance)
- **`pydantic-to-typescript` 库 vs Hand-rolled 选择**:v16.1 starter 12 DTO 不复杂,hand-rolled 够用 + 0 external dep 风险。v16.4+ 若 DTO 复杂度上升,可考虑切回 library
- **Pydantic v2 `ConfigDict(extra="ignore")`**:forward-compat — row 增加字段不破前端
- **TS re-export shim 在 `dashboard-contracts/`** 而非直接跨包 import Python 模块 (pnpm workspace 不知道 Python 包存在)
- **knip allowlist rule**:v16.2+ 加 typed wrapper 时,记得把 unused file + dep 加 allowlist
- **CI `setup-uv` cache 必加** — 避免 2-3 min 重复下载 per run
- **`sleep N` → readiness poll** 在 cold CI 上更稳 (5s fixed sleep 偶发 flake)
- **Pre-existing pytest debt** (agent_system/dashboard) 与 v16.1 无关,不阻塞闭环 (T1 baseline 已记录)
