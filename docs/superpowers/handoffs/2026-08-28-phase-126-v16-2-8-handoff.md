## 3. Lessons learned

1. **Re-export shim mocks don't propagate** (v16.2.7 §3 lesson 1, RE-CONFIRMED): When composables migrate from `@/api/index.js` barrel to typed wrapper, parallel mock is REQUIRED. Hoisted `mocks` variable pattern is the cleanest implementation:
   ```ts
   const mocks = vi.hoisted(() => ({ xxx: vi.fn(), yyy: vi.fn() }))
   vi.mock('@/api/index.js', () => mocks)
   vi.mock('@/api/{typed}.js', () => ({ xxx: mocks.xxx, yyy: mocks.yyy }))
   ```
   Without hoisting, each `vi.mock` factory creates fresh vi.fn instances per module path → assertions on the typed wrapper miss calls invoked through the barrel.

2. **14 page-level tests** needed this fix in T3.A alone. The pattern is mechanical but tedious. Future batch migrations should plan for this upfront.

3. **`as unknown as` cast pre-existing DTO drift**: v16.2.7 §5.1 lesson 4 re-confirmed. Typed wrapper strict types exposed 4 pre-existing fixture-level DTO field mismatches (`advice_only`, `candidates`, `quality_hints` in `creator-write-workbench.spec.ts`). Casts preserve runtime behavior; full schema fix deferred to v16.4+ DTO audit.

4. **`as unknown as` cast for typed wrapper body param**: T4.5 surfaced same issue in `useAgentTask.ts:342-346`. `body` is built dynamically as `Record<string, unknown>`, but typed wrapper now strict. Pattern: `body as unknown as Parameters<typeof runCreatorAgentPlan>[0]`.

5. **Dead code in legacy modules**: 4 functions in `mergePreset.js` (DiffColab + Wizard helpers) had zero consumers. Per v16.2.7 §5.1 lesson 6, deleted without ceremony. Also: `studio.js` was redundant with new `studio.ts` since v16.2.7 T2 was applied.

6. **Architecture guards can be inverted**: When a guard's premise becomes invalid (file no longer exists), invert the guard rather than deleting it. Preserves intent.

7. **`studio.js` discovery**: Recon missed `studio.js` because original T5 plan only listed 5 modules + creator.js (per handoff carryover). Bulk verification (`ls apps/dashboard/src/api/*.js`) would have caught it.

8. **Bulk sed for function renames**: 17 of `useCreatorSettings.js` Creator-prefixed → unprefixed renames were done via single multi-`-e` sed command. Clean and atomic.
