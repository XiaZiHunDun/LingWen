## 5. Lessons

- **uv workspace 不需要 `[tool.uv] package = true`**:每个 member 只要有标准 `[project]` section,uv 自动识别。"package = true" 是 cosmetic 可选项。**Plan T3 的 cosmetic step 可以省**
- **Python 包名不能有 hyphen**:Hyphen path 仅作 packaging metadata 容器,Python 模块名仍是下划线(`apps.studio_api`)。**Plan T4 用 hyphen path 是 bug**
- **infra/app 双层 ruff config 需谨慎**:子包 `apps/studio_api/pyproject.toml` 里的空 `[tool.ruff]` section 会**覆盖** root 的 ignore 列表,导致 F401/E402 复出。空 section = 完全 override
- **uv sync 不保证 member 目录存在**:workspace member 缺目录时 uv silently skipper,CI 不会报错。**Phase 126 v16.0.1 candidate**:加 `tooling/hygiene/check_workspace_members_exist.py` CI gate
- **grimp/import-linter 装在哪个 env**:uv 加 to `[dependency-groups]` 仅装到 uv venv,miniconda python(本项目 pytest 用的)看不到。**CI 必须 `uv run --with-dev` 或先 `pip install grimp import-linter`**(本 handoff 已 pip install 到 miniconda)
