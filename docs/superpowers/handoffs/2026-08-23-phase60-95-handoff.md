## 3. Established Conventions

### 3.1 Commit Message Format


- `docs: bump CLAUDE.md to v13.2 (Phase 81-88 maintenance close)`
- `build(ci): add knip for dead-export detection (Phase 95)`

### 3.2 Workflow (Phase 60-95)

Each phase strictly:
1. **Explore** (TaskCreate + verify state)
2. **Brainstorm** (skill + 3 options question + 1 OK)
3. **Spec** → user review → commit
4. **Plan** (writing-plans skill + 2 OK)
5. **Execute** (subagent-driven for code, inline for docs)
6. **Push** to origin (manual commit + push)

**Key skills**:
- `superpowers:brainstorming` — design questions + approval
- `superpowers:writing-plans` — bite-sized task plans
- `superpowers:executing-plans` — execute inline
- `superpowers:subagent-driven-development` — for code changes
- `superpowers:finishing-a-development-branch` — push/merge

### 3.3 File Structure Convention

**Per-phase 3 files** (committed separately):
- `docs/superpowers/specs/YYYY-MM-DD-phaseNN-<topic>-design.md` (spec)
- (optional) `docs/superpowers/specs/YYYY-MM-DD-phaseNN-<topic>-design.amend.md` (amend)
- `docs/superpowers/specs/YYYY-MM-DD-phaseNN-<topic>-final-state.md` (for audits only)
- (optional) code changes (1+ files depending on phase)
- `docs/superpowers/plans/YYYY-MM-DD-phaseNN-<topic>.md` (plan)

### 3.4 Risk Patterns

**Subagent-driven workflow has BLOCK pattern**: spec plan can miss test/mock references. Implementer correctly BLOCKs on first encounter. Pattern (Phase 84 + 85 + 91):
1. Implementer BLOCKs with finding
2. User/spec author amends spec (expand scope to include test file)
3. Implementer retries with expanded scope
4. Code quality reviewer may also find MEDIUM (e.g., hardcoded value in error message) → amend + retry
5. User commits + pushes

**Plan Step "delete keyword issue"**: bash interprets `delete` as command in commit message body. Mitigation:
- Use `commit --amend --file=- <<'COMMIT_EOF'` heredoc, OR
- Use `commit --amend -m "subject" -m "body line 1" -m "body line 2"` (separate `-m` per line)

### 8.3 ESLint Rule Test Pattern (Phase 82+88)
```js
const { RuleTester } = require('eslint')
const rule = require('./rule-name.js')

const ruleTester = new RuleTester({
  languageOptions: { ecmaVersion: 2022, sourceType: 'module' },
})

ruleTester.run('rule-name', rule, {
  valid: [/* ... */],
  invalid: [/* ... */],
})
```

### 8.4 Subagent-Driven Execution Pattern
1. Main session runs writing-plans skill
2. Dispatch implementer subagent (general-purpose, sonnet)
3. Dispatch spec reviewer subagent (code-reviewer, sonnet)
4. Dispatch code quality reviewer subagent (code-reviewer, sonnet)
5. If MEDIUM found, dispatch fix subagent (amends commit)
6. Main session: finishing-a-development-branch skill → commit plan + push
