## 4. 约定的开发流程 (Phase 60-74 沿用)

每个 phase 严格 4-step:

1. **Explore** (`TaskCreate` + 探索 candidate)
2. **Brainstorm** (brainstorming skill + 3 options question + 1 OK)
3. **Spec** → user review → commit
4. **Plan** (TaskCreate / write-plans skill / 2 OK `1`)
5. **Execute via subagent-driven** (Phase 74: 1 implementer + 1 spec review + 1 code quality review)
6. **Push** to origin (user command)

**关键 skills**:
- `superpowers:brainstorming` — 一个 candidate + approach + spec/design sections + user review
- `superpowers:writing-plans` — 2 OK 后 plan
- `superpowers:subagent-driven-development` — implementer + spec review + code quality review
- `superpowers:finishing-a-development-branch` — push

## 5. Commit 规范

- **Conventional commits**: `<type>(<scope>): <subject>` (e.g., `perf(ImpactGraph): remove deep:true from watch`)
- **Type 范围**:
  - `perf` — 性能优化
  - `refactor` — 重构
  - `chore` — maintenance / housekeeping
  - `test` — 测试
  - `docs` — 文档
  - `build` — build config
  - `fix` — 修复
  - `feat` — 新功能
- **Bilingual body**: 中文 subject rationale
- **Atomic commits**: 1 atomic change per atomic commit
- **Trailing newline**: 必加 (Phase 65 项目-wide)
- **No push**: 实施 → 用户确认 → push
