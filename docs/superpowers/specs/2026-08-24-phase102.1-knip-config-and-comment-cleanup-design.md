## 1. Context

Phase 102 deleted 30 unused files + added 5 false-positives to `knip.json#ignore`, then out-of-plan Commit 3 (`06e124fd`) moved `knip.json` from repo root to `apps/dashboard/knip.json` because knip doesn't walk up parent directories. The code-quality reviewer flagged two follow-ups:

### Issue 1 (MEDIUM): Root-level `pnpm exec knip` regression

After Commit 3, running `pnpm exec knip` from the repo root finds no config file (because the only `knip.json` is now at `apps/dashboard/knip.json`), and knip falls back to scanning the entire monorepo (`fn-core/`, `packages/*`, `scripts/`, `trae比赛/`) — reporting 35 unused files from unrelated directories. CI is unaffected (it uses `working-directory: apps/dashboard`), but developers running `pnpm knip` from the repo root now see misleading output.

**Fix**: Add a delegation script to root `package.json` so `pnpm knip` works correctly from any directory.

Phase 102 deleted 20 Creator sub-components, but the corresponding `creatorXxxKey.js` files (Symbol-based provide/inject helpers) were preserved because they're still imported by `useCreatorPageProviders.js`. ## 4. Design

### 4.1 Change Set

**Edit 1**: `package.json` — add 1 line to `scripts` block.

Current root `package.json` scripts:
```json
"scripts": {
  "build": "pnpm -r --filter './apps/*' --filter './packages/*' build",
  "lint": "pnpm -r --filter './apps/*' --filter './packages/*' run lint",
  "test": "pnpm -r --filter './apps/*' --filter './packages/*' run test",
  "typecheck": "pnpm -r --filter './apps/*' --filter './packages/*' run typecheck"
}
```

New:
```json
"scripts": {
  "build": "pnpm -r --filter './apps/*' --filter './packages/*' build",
  "lint": "pnpm -r --filter './apps/*' --filter './packages/*' run lint",
  "test": "pnpm -r --filter './apps/*' --filter './packages/*' run test",
  "typecheck": "pnpm -r --filter './apps/*' --filter './packages/*' run typecheck",
  "knip": "pnpm exec knip --config apps/dashboard/knip.json"
}
```

The new line is appended after `typecheck`. The `--config` flag points knip at the actual config file regardless of cwd.

**Edit 2-6**: 5 creator key file JSDoc updates — line 2 of each file.

For each file, replace the stale Panel reference with a generic description that doesn't reference a specific component name.

Example for `creatorAdvanceBatchKey.js`:
```diff
 /**
- * Injection key for CreatorAdvanceBatchPanel bindings in pulse column.
+ * Injection key for advance-batch bindings (pulse column bindings).
  */
```

Pattern: Remove the Panel name and use a lowercased variant of the same domain.

### 4.3 Risk Analysis

- **package.json edit risk**: Very low. Adding a script is additive — no existing script changes behavior. Existing `pnpm build/lint/test/typecheck` unchanged.
- **Comment edit risk**: Zero functional impact. JSDoc comments are documentation only. Engineers reading the file get accurate context.
- **Test risk**: None. No source code logic changes. 1545 existing tests still apply.
- **Lint/type-check risk**: None. ESLint/TypeScript don't enforce JSDoc content.
- **knip risk**: None. The key files' exports are unchanged (Symbol + factory function). Knip won't pick up new "unused" anything.
