# Phase 15.1 REQ-001 — 创作者模式增强

## 概述

增强三种创作模式（companion/advance/studio）的用户体验，重点改进模式切换的直观性、陪伴模式的引导式写作流程、以及推进模式的批量操作能力。

## 现状分析

当前三种模式的区别主要在于导航可见性和目标卡片文字：

| 模式 | 特点 | 限制 |
|------|------|------|
| companion | 简洁界面，隐藏生产入口 | 缺乏引导式写作流程，模式切换不直观 |
| advance | 功能全开 | 批量操作能力有限，统计信息不够详细 |
| studio | 工厂模式，隐藏书桌 | 缺乏模式切换引导 |

## 增强方案

### 1. 模式切换 UX 优化（高价值，低风险）

**目标**: 让用户清楚当前所处模式，并能轻松切换

**改动**:
- 在写作工作台头部添加模式指示器和切换按钮
- 创建模式切换面板组件
- 更新 `useCreatorWriteWorkbench.js` 添加模式切换逻辑
- 更新后端 API 支持模式切换

**影响文件**:
- `dashboard/frontend/src/components/creator/CreatorWriteWorkbench.vue` — 添加模式指示器
- `dashboard/frontend/src/components/creator/CreatorModeSwitch.vue` (新) — 模式切换面板
- `dashboard/frontend/src/composables/useCreatorWriteWorkbench.js` — 添加模式切换方法
- `dashboard/frontend/src/api/creator.js` — 添加模式切换 API
- `dashboard/helpers/creator.py` — 后端模式切换接口

**验证**:
- vitest 测试模式切换组件
- check-frontend.sh 验证构建

---

### 2. 陪伴模式引导式写作流程（高价值，中风险）

**目标**: 在 companion 模式下提供更清晰的写作引导

**改动**:
- 增强本章意图输入区域，添加模板提示
- 添加写作步骤引导（构思 → 起草 → 润色 → 检查）
- 为 AI 续写添加更多选项（扩展、重写、润色）

**影响文件**:
- `dashboard/frontend/src/components/creator/CreatorWriteWorkbench.vue` — 增强意图输入和引导
- `dashboard/frontend/src/composables/useCreatorWriteWorkbench.js` — 添加写作步骤状态管理
- `dashboard/frontend/src/composables/useCreatorAgent.js` — 添加更多 AI 操作类型

**验证**:
- vitest 测试写作流程状态
- Playwright e2e 测试引导流程

---

### 3. 推进模式批量操作增强（中价值，中风险）

**目标**: 在 advance 模式下增强批量处理能力

**改动**:
- 添加批量章节选择
- 添加批量 AI 续写/润色功能
- 增强统计面板，显示更多详细信息

**影响文件**:
- `dashboard/frontend/src/components/creator/CreatorWriteWorkbench.vue` — 添加批量操作按钮
- `dashboard/frontend/src/composables/useCreatorWriteWorkbench.js` — 添加批量操作方法
- `dashboard/frontend/src/composables/useCreatorAdvanceBatch.js` — 增强批量处理逻辑

**验证**:
- vitest 测试批量操作逻辑
- check-frontend.sh 验证构建

---

### 4. 写作目标和意图管理增强（中价值，低风险）

**目标**: 更好地管理写作意图和目标

**改动**:
- 意图标签扩展（当前只有情绪标签：克制/戏剧/幽默/抒情）
- 添加写作目标追踪（完成百分比、字数目标）
- 意图历史记录，便于复用

**影响文件**:
- `dashboard/frontend/src/components/creator/CreatorWriteWorkbench.vue` — 扩展标签和目标显示
- `dashboard/frontend/src/composables/useCreatorWriteWorkbench.js` — 添加目标追踪和意图历史

**验证**:
- vitest 测试意图管理功能

---

### 5. 模式专属 UI 优化（低价值，低风险）

**目标**: 为每种模式提供更鲜明的视觉区分

**改动**:
- 为不同模式设置不同的主题色/强调色
- 模式专属的空状态提示
- 模式专属的快捷操作区

**影响文件**:
- `dashboard/frontend/src/components/creator/CreatorWriteWorkbench.vue` — 添加模式专属样式
- `dashboard/frontend/src/assets/creator-write-workbench.css` — 添加模式主题变量

**验证**:
- 视觉检查
- check-frontend.sh 验证构建

## 风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 模式切换导致状态丢失 | 中 | 切换前保存草稿，切换后恢复 |
| 批量操作性能问题 | 中 | 限制单次批量操作数量，添加加载状态 |
| 后端 API 变更影响其他模块 | 低 | 保持向后兼容，添加版本控制 |
| 样式冲突 | 低 | 使用 scoped 样式，避免全局污染 |

## 验证策略

1. **单元测试**: 每个新组件和方法都有对应测试
2. **构建验证**: 每次改动后运行 `check-frontend.sh`
3. **端到端测试**: Playwright 测试核心流程
4. **手动验证**: 视觉检查和交互测试
